# Retained portrait and creation lessons

## 2026-10-04 — A green full gate closes test proof, not runtime activation

- Record the successful owner's source fingerprint; do not infer missing test counts from a tail.
- Disposable database proof does not apply real-store schema/grants or activate photo providers.

## 2026-10-04 — Fix the schema population instead of narrowing its protection check

- Portrait payloads belong in the persona table family with the shared immutable trigger.
- Keep exact action inventory assertions; obtain owner approval before extending the blocked test.

## 2026-10-04 — Give the portrait a place without implying it is saved

- A full image frame beside compact details gives Creation a clear focus. Keep mobile document
  order, native picker focus and explicit save confirmation aligned with the visual layout.
- Disconnected preview must block attachment until checked, preserve text on discard and
  never present a selected image as a saved or verified identity.

## 2026-10-04 — Dependency presence is not isolated worker availability

- Real Pillow pixels decode after installation, but Mac memory-limit setup fails before worker
  decoding. Classify that as unavailable, preserve limits and verify the bounded Linux runtime.
- Preview/checked upload/immutable version binding are distinct states. Keep exact upload retry,
  reject late/session-mismatched receipts and never treat staging expiry as deletion permission.

## 2026-10-04 — A creation receipt must replace the submitted form

- Appending success below a long form can hide it at the submit scroll position. Replace the
  editor, focus the confirmation heading and put record IDs in a collapsed receipt.
- Opening the saved record still needs a fresh authorized read. Restore only the authored
  completion marker on re-entry; retaining a fetched receipt would cross the draft boundary.

## 2026-10-04 — Prefilled editing must preserve session-scoped authored drafts

- Initialize the editor from the authorized saved version only when no local draft exists.
  Another session receives its own fetched version, never the previous session's edits.
- Uniform toolbar geometry needs explicit height and minimum-height; an inherited minimum
  can make Refresh larger. DOM tests verify behavior, not rendered geometry or touch targets.
